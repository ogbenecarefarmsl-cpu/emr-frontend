## 1. Doctor Order Editing Feature

### Problem
Doctors could create lab orders and prescriptions but had **zero ability to edit them** after creation. Once created, orders/prescriptions were immutable from the doctor's interface.

### Backend Changes (emr-backend)

#### `src/orders/dto/update-order.dto.ts`
- Expanded with `tests?: OrderTestDto[]`, `priority?: PriorityEnum`, `discount?: number`, `discountType?: DiscountTypeEnum`

#### `src/orders/orders.service.ts` — `update()` method rewritten
- **Guard**: Only `awaiting_payment` status can have tests changed; `pending_collection` can only change priority/notes
- When tests change: deletes old `OrderTest` records, creates new ones, recalculates subtotal/total/balance
- Updates `lisRequestedCodes` for lab orders
- Triggers LIS re-sync if tests changed on already-synced orders
- Emits real-time events

#### `src/prescriptions/dto/update-prescription.dto.ts` (NEW FILE)
- `items?: PrescriptionItemDto[]`, `notes?: string`, `totalAmount?: number`

#### `src/prescriptions/prescriptions.service.ts` — `update()` method added
- Guards: only `pending` + unpaid prescriptions can be edited
- Replaces items array, re-generates label instructions
- Emits `prescription:updated` event

#### `src/prescriptions/prescriptions.controller.ts`
- Added `PATCH /prescriptions/:id` for `ADMIN`, `DOCTOR`, `SPECIALIST`

### Frontend Changes (emr-frontend)

#### `src/services/prescriptionService.ts`
- Added `update()` method: `api.patch(\`/prescriptions/${id}\`, data)`

#### `src/hooks/useOrders.ts`
- Expanded `OrderUpdate` interface with `tests`, `discount`, `discountType` fields

#### `src/pages/doctor/DoctorDashboard.tsx`
- **Existing Orders section** in Orders tab showing lab orders + prescriptions with Edit buttons
- **Edit state** (`editingOrder`, `editingPrescription`) to track what's being edited
- **`startEditOrder`/`startEditPrescription`** helpers that pre-populate the modals
- **`updateLabOrder`/`updatePrescription`** mutations calling the new APIs
- **Edit buttons** only visible when order is `awaiting_payment` or prescription is `pending` + unpaid
- **Modals** show "Edit" titles and "Update" buttons when in edit mode
- Clear edit state when opening modals for new orders

### Business Rules
| Rule | Enforcement |
|------|-------------|
| Only edit before payment | Backend checks `paymentStatus === 'pending'` |
| Tests only editable on `awaiting_payment` | Backend status guard |
| Prescription edit only when unpaid + pending | Backend `isPaid` + `status` check |
| LIS auto-re-sync on test changes | Backend after update |

## 2. Patient Pages UX/UI Overhaul

### Problem
Both patient detail pages looked "like a joke" — plain text, no visual identity, no hierarchy, boring empty states.

### Changes Made

#### `src/pages/reception/PatientDetails.tsx` (824 → rewritten)
- **Patient header card**: Gradient background, avatar circle with initials, name, patient ID badge
- **Badges row**: blood type (red), allergies (destructive), MRN, address with icons
- **Quick stats strip**: Total Orders, Total Spent (Le), Wallet Balance, Last Visit
- **Orders tab**: Rounded cards with color-coded status badges, test badges, price
- **Result History**: Cleaner accordion, better table formatting
- **Wallet**: Polished card styling
- **Empty states**: All tabs show centered icons with descriptive text
- **Edit mode**: Inline card form instead of replacing entire view

#### `src/pages/shared/PatientRecord.tsx` (637 → rewritten)
- **Patient header**: Gradient background, avatar, ID, gender, age, phone, badges
- **Quick stats**: Consultations, Prescriptions, Lab Orders, Last Visit with icons
- **Timeline**: Color-coded SOAP entries and lab orders in vertical timeline
- **Lab Results**: Better card layout, panel grouping, LIS sync badges
- **Prescriptions**: Medication cards with dosage, route, instructions
- **SOAP Notes**: Color-coded subjective/objective/assessment/plan sections
- **Vitals**: Clean table with proper spacing
- **Empty states**: All 5 tabs show centered icons with descriptive text

#### `src/pages/reception/PatientsPage.tsx`
- **Patient avatars** with initials in circle
- **Gender badge** instead of plain text
- **Wallet balance** in green
- **Empty state** with icon and registration prompt
- Better row hover styling
